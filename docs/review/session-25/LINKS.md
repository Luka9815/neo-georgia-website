Run `NODE_USE_ENV_PROXY=1 npm run check:links` after a clean build, using the same SITE_URL and PATH_PREFIX as that build. Every distinct hand-entered built-site URL is checked; generated snapshot card URLs are randomly sampled without replacement, default 200. Explicit authored references take precedence over generated classification. Own-origin URLs are internal and excluded. Configure `PROJECT_SAMPLE_SIZE`, `ERASMUS_DELAY_MS` (default 500 ms between Erasmus+ host requests, including fallbacks) and optionally `LINK_AUDIT_DIR`. The checker uses HEAD with GET fallback, follows redirects and uses an eight-second timeout. It preserves 403/429 results without retries. Each completed URL is appended immediately to results.jsonl; inventory.json records the selected sample before requests start, and results.json is written on completion. Interrupted runs retain their completed results. The checker remains outside build, full test execution and CI; unit tests exercise only selection with no network requests.
