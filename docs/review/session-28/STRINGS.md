# Session 28 strings for proofreading

Existing headings, IDs, link labels, descriptions and credit wording stay in their original records. The Home eyebrows and return link are the new interface strings.

| Use | Georgian | English |
| --- | --- | --- |
| Find eyebrow | Erasmus+ საქართველოში | Erasmus+ in Georgia |
| Opportunities eyebrow | სექტორების მიხედვით | By sector |
| Figures eyebrow | პროექტების მონაცემები | Project snapshot |
| Calls eyebrow, when there are open or upcoming calls | დაფინანსების შესაძლებლობები | Funding opportunities |
| Events eyebrow, when there are upcoming events | ღონისძიებების კალენდარი | Event calendar |
| News eyebrow | ოფისის სიახლეები | From the office |
| Stories eyebrow, when a story is published | პროექტების გამოცდილება | Project experiences |
| Return link in the header | გვერდის დასაწყისში | Back to top |

Events and Stories use the existing empty-state strings and calendar or Resources link labels. Key Action chips retain the full translated prefix in their accessible text. Sector chips use the existing translated project sector names. The river photo credit uses the existing modification string for an overlay at its new placement.
